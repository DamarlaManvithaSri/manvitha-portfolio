## ⚡ The Creative Feature: "Manvitha-CLI"

### What It Is:
A fully functional interactive web terminal emulator (`manvitha@amrita-ai:~$`) that allows visitors to explore my background, technical superpowers, and guiding philosophy through executable commands.

### How Visitors Discover It:
- **Visible Pulsing Launcher:** A floating widget (`>_ CLI Mode`) at the bottom-right of every page with a pulsing radar wave and an interactive hint bubble: *"⚡ Psst! Try the live terminal"*.
- **Quick Command Chips:** Visitors on mobile or those who prefer not to type can click 1-tap command buttons:
  - `help` — Lists all commands
  - `about` — Prints academic and degree details
  - `skills` — Outputs technical competencies
  - `ghost-audit` — **Runs a real-time animated cybersecurity data audit simulation**
  - `motto` — Displays my core personal philosophy
  - `socials` — Lists verified profiles
  - `clear` — Clears the terminal screen
- **Zero-Block Navigation:** The terminal never locks or obstructs standard page scrolling and can be reset or exited at any time.

## 🚀 Running Locally

To run this portfolio locally without any dependencies or install steps:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/DamarlaManvithaSri/manvitha-portfolio.git
   cd manvitha-portfolio
   ```
2. Open `index.html` in any modern web browser:
   - On Windows: Double-click `index.html` or open in Chrome/Edge.
   - Or use VS Code Live Server extension.
